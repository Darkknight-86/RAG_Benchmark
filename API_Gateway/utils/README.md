# API Gateway Utilities

This directory contains utility scripts and tools for manual testing and development.

## Scripts

### `manual_export.py`
- **Purpose**: Manual testing script for RAGBenchmarks system
- **Usage**: `python manual_export.py`
- **Note**: This is for development/testing only. Production metrics use `enhanced_metrics.py`

## Notes

- The main application uses `enhanced_metrics.py` for all real-time metrics
- These utilities are for debugging, testing, and development purposes
- Do not use these in production code
